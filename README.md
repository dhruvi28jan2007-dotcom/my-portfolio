## 🚀 How to Run & Preview Locally

### Option 1: Direct Browser Open (Easiest)
Simply double-click `index.html` in your file finder to view it in Chrome, Safari, Edge, or Firefox!

### Option 2: Local HTTP Server (Recommended)
Open your terminal in this folder and run:
```bash
python3 -m http.server 8080
```
Then visit: `http://localhost:8080` in your web browser.

## 🌐 Free 1-Minute Deployment Options

### 1. GitHub Pages (Best for Developers)
1. Initialize git and commit:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of portfolio"
   ```
2. Create a repository on GitHub (e.g. `dewadi-portfolio` or `dewadisrivastava.github.io`).
3. Push your repository:
   ```bash
   git branch -M main
   git remote add origin https://github.com/dewadisrivastava/dewadi-portfolio.git
   git push -u origin main
   ```
4. Go to **Settings** > **Pages** > Select `main` branch > Click **Save**. Your site will be live instantly!

### 2. Vercel or Netlify
- Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com) for instantaneous global CDN deployment.
